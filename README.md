## 便宜的套餐便宜在哪：三个独立计费项

云服务器的账单从来不是“实例价格”一个数。阿里云 ECS 这边，实例算力、系统盘、数据盘、公网带宽、EIP、快照是分开计价的，只看实例报价做预算，实际账单翻倍是常事。

**带宽是最贵的那一项。** 阿里云华北2（北京）地域，预付费固定带宽 1Mbps 收 23 元/月，5Mbps 收 125 元/月，6Mbps 以上每 Mbps 80 元/月。也就是说，一台 2核2G 的 ECS 如果配 5M 独享带宽，光带宽一年就是 1500 元，比机器本身贵得多。这就是为什么很多“99 元/年”的 ECS 只给 3M 带宽，扩到 5M 价格立刻变脸。

**云盘按月计费。** ESSD Entry 云盘 0.35 元/GiB/月，ESSD PL0 是 0.5 元，PL1 是 1 元，SSD 云盘也是 1 元。40GB 系统盘用 ESSD Entry 一年约 168 元；换成 100GB 的 SSD 云盘，一年 1200 元。轻量应用服务器把系统盘打包进套餐，ECS 要自己选，选错盘型差价能有十倍。

**流量和限速是隐形天花板。** 流量包模式超出额度后单独产生流量费，按使用量计费约 0.8 元/GB；标“不限流量”的套餐，带宽上限是固定的，跑满就限速。峰值带宽和独享带宽也不是一回事：阿里云轻量的 200M 是峰值，实际持续吞吐受流量包和调度策略限制；京东云、芯飞云标的 5M、10M 通常是独享。

雨云 RCS 的报价里带宽是含在套餐内的，10M 上行 / 50M 下行这类上下行不对称的配置，在 ECS 体系里没有直接对应项，所以别拿它的月付价去和“裸实例价”硬比，口径不同。下单前问清楚两件事：这个带宽是独享还是峰值，流量超了怎么收。

还有两个新手常踩的坑：弹性公网 IP 不绑定实例、只保留着，照样计费；按量付费的实例用完不释放，CPU 空转也一直扣钱。按量计费最小粒度精确到秒，听起来灵活，实际跑满一个月并不便宜：阿里云 c9i 2核4G 按量约 0.44 元/小时，一个月 720 小时算下来 316 元，而同一规格包年包月折合月单价约 210 元。

## 轻量应用服务器和云服务器，差的是能不能改

同规格下，轻量和云服务器的 CPU、内存性能基本相当，差别在网络配置的灵活性和高级功能上。

轻量应用服务器把实例、系统盘、带宽、流量包打包成一个固定套餐，预装 WordPress、LAMP、Node.js 这类应用镜像，买完登录后台就能发文章。代价是套餐规格固定，腾讯云轻量只支持套餐升级、不支持降级，网络侧也不给你 VPC、弹性网卡、负载均衡这些。

云服务器（ECS / CVM / 雨云 RCS 都属于这一类）的 vCPU、内存、磁盘、带宽、安全组各自独立配置，能挂负载均衡、对象存储、数据库，能做多实例集群。灵活的另一面是账单拆成好几项，得自己规划。

判断标准很简单：

- 只跑一个站或一个接口，没有集群规划，不想碰网络配置，选轻量。
- 半年内可能加机器、上微服务、接数据库和负载均衡，直接上云服务器，别等业务长起来再迁移。
- 数据库这类核心业务优先独享型实例，共享型在高峰期被邻居抢资源，性能波动排查起来很费劲。

顺带纠一个常见误解：1核1G 装 WordPress 再开几个插件，可用内存会紧张到后台都卡。个人站从 2核2G 起步是合理的下限，不是浪费。

## 首年 38 元不是重点，第二年多少钱才是

阿里云 2核4G 的活动价 800 多元/年，续费可能跳到 1400 元。包年包月到期后按原价续费，高于活动采购价，这是行业通例。少数套餐例外，比如阿里云经济型 e 的 99 元/年明确写了新老用户同价、续费也是 99 元，每年有一次原价续费机会。

所以比价时至少要看两个数：首年实付，和第二年按什么口径续。

雨云这边的规则是周期折扣长期有效，年付 7 折对老用户同样适用，但新用户的首月 5 折券只在注册时发一次，续费时没有可用的优惠码。也就是说，第一年 84 元的 2核2G，第二年如果继续年付，大概还是 84 元这个量级，不会出现首年 84、次年翻倍的情况。这个结构比“首年超低价 + 原价续费”要好算，代价是首年价格本身没有秒杀款那么刺激。

另外提醒一句：38 元、28 元这类价格基本是秒杀或新客限时款。阿里云那个 38 元/年的轻量 2核2G 需要抢，每天上午 10 点和下午 3 点两场，抢不到就是 68 元；腾讯云的 38 元是 4核4G 新客专享，同配置标准入门款在 88 到 99 元/年。如果你不想定闹钟，10 元/月的常规价反而省心。

## 按场景给结论

**个人博客、学习环境、折腾用**：大陆节点 2核2G，10 元/月。年付 84 元，玩坏了重装就行。新用户领了首月 5 折券，第一个月成本 5 元。

**小程序后端、企业官网、低并发 API**：2核4G，19 元/月。1核1G 和 2核2G 在这个场景会卡在内存上，省下的钱不够填迁移的工时。

**要跑 Docker 多容器、多个站点**：4核8G，58 元/月。轻量的固定套餐在这种场景下扩展性不够，容易卡住。

**外贸站、需要境外访问**：香港或洛杉矶节点 2核2G，28 元/月，200M 带宽加 1024GB 月流量，比大陆节点的 10M / 50M 宽裕得多。

**AI 推理、模型部署**：先用一句话排除掉绝大多数人。业务只是网站、接口、数据库，不需要 AI 训练推理，GPU 机型直接不用看。确实要做推理，再去看 P40 系列，并且先确认显存够不够，显存不足模型直接加载失败。

**临时测试、压测、短期任务**：按量计费，用完手动释放实例和 EIP。别放着不管。

## 下单前确认这几件事

1. **续费价**。问清楚第二年按什么价续，周期折扣是否长期有效，新用户券是不是只发一次。
2. **带宽口径**。是独享还是峰值，上行下行各多少，跑满了是限速还是额外收费。
3. **流量超额**。月流量额度多少，超了按什么单价收。
4. **备案**。业务需要 ICP 备案，必须选包年包月实例，按量实例的备案支持受限；境外节点不适用。雨云各节点是否支持备案要单独确认。
5. **退款**。雨云的退款政策是新购产品 7 天内无理由退，在控制面板自助操作，每位用户限 3 次；领过积分、1 元试用或续费的产品、以及超过 7 天的订单不支持；日付、流量包、IP、升级这类非月付产品也不在无理由范围内。先买一个月试，比一次买三年稳。
6. **按量实例用完释放**。实例、EIP、快照都要清，保留状态一样计费。

不确定配置够不够，最省事的办法是先用最小的一个月跑起来，看 CPU 和内存的实际占用再决定要不要升。10 元起步的试错成本，比对着参数表猜半天划算。
